# 公司与账套

状态：组织、公司与账套的首期对应关系已于 2026-10-23 确认；其他基础设置待审阅，尚未开始实现。

## 目的

定义公司、账套与组织的关系及账务边界。

## 已确认的对应关系

- 组织管理团队、成员和权限，一个组织可以管理多个公司。
- 首期每家公司对应一个独立账套。
- 账套是记账单位，科目、凭证、余额和流水应明确属于该账套。
- 组织本身不直接记账，也不因为旗下有多个公司就自动汇总它们的账务。

例如，一个组织管理公司 A 和公司 B，A 与 B 首期各有一个独立账套。两家公司即使使用相同科目编码，也不能把凭证和余额混为一套账。跨公司查询或汇总如有需要，应单独明确范围、口径和权限。

## 访问边界

组织管理员管理本组织全部账套；普通成员仅访问被分配的账套，并分别具有只读或可编辑权限。属于同一组织不表示普通成员自动能够看到所有公司的账务。具体规则见[组织 成员与权限](02-organizations-permissions.md)。

“一个组织可有多个公司、首期每家公司一个账套”已经确认，不再作为待决问题。一家公司多账套不属于本次已确认的首期模型，如后续需要，应单独调整需求。
