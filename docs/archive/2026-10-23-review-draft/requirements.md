# Earlier requirements draft

Status: Superseded discussion draft. Not approved.

## Why this file remains

The first draft focused on account management before the project adopted an organization-first plan. It proposed account codes and names, account types, grouping, enable/disable rules, permissions, audit, balances and ledger activity.

Those suggestions were not blanket-approved. This file does not authorize implementation and is not the source of current requirements.

## Historical proposals

The earlier draft suggested a flat account list, unique account codes, possible unique names, restricted changes to used accounts and conservative account deactivation. It also proposed separate milestones for account master data and real accounting queries.

These remain proposals unless the current chapter and decision record explicitly say otherwise. The original wording is preserved in Git history; this short English summary replaces it for readability.

Later confirmed changes include multiple organizations, one ledger per company, the two-role access model, invitation policies, API/MCP principles and the C# direction. See the decision record for their exact scope.
