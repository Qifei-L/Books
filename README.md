# Books

Books 是一个处于需求与文档定义阶段的记账后端项目。

## 当前阶段

- 先搭建文档骨架，再逐章审阅和完善。
- 多组织优先；组织与公司账套的关系仍待确认。
- Web 暂不纳入，尚未开始代码实施。
- 后端改用 C# + ASP.NET Core + EF Core + PostgreSQL，模块化单体、API/MCP 优先，首期不引入 ABP。
- 会计引擎、身份供应商、精确依赖版本及部署细节仍待确定。
